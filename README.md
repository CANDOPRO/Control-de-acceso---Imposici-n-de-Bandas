#FLOR NORMALISTA 2026 — CONTROL DE ACCESO

#ARCHIVO PRINCIPAL
- index.html: aplicación web completa, sin instalar programas.

#CÓMO USARLA
1. Abre index.html en un navegador moderno para probarla.
2. Para usarla desde el celular con una dirección web, publica index.html en un hosting estático (por ejemplo, GitHub Pages, Netlify o similar).
3. Usa siempre el mismo navegador y dispositivo durante el evento.
4. Pulsa “Descargar respaldo” antes de comenzar y periódicamente durante el evento.

#GUARDADO
Los folios se guardan en localStorage del navegador y sobreviven a recargas y cierres normales del navegador. No se sincronizan entre dispositivos ni navegadores. No borres los datos del sitio ni uses modo incógnito. Si publicas la página en un hosting, utiliza siempre exactamente el mismo dominio/dirección, porque el almacenamiento está asociado al origen del sitio.

#IMPORTANTE
Esta versión no requiere conexión a Internet para registrar los folios una vez que el archivo está abierto, pero al publicarla necesitarás conexión para abrirla por primera vez. No es una base de datos en la nube: la recarga de datos del celular o una conexión móvil no sustituyen los respaldos. Descarga y conserva un archivo JSON de respaldo.
